A closed program of Padovani and Novara that types and gets stuck, and the repairs

Source. L. Padovani and L. Novara, Types for Deadlock-Free Higher-Order
Programs, FORTE 2015, LNCS 9039, pp. 3-18, HAL copy hal-01767327. Page numbers
are pdf pages of that copy. Constant schemes are on p. 7, the typing rules
(Table 2) on p. 8, values, reduction contexts and reduction on p. 5, infinite
types and contractiveness on p. 12, wrap v as a value on p. 13, Definition 1 and
Theorem 2 on p. 14. The program was checked by hand against these rules. It is
not machine checked.

Notation. → abbreviates →^{⊤,⊥} (p. 7). Types are possibly infinite trees
generated by the productions for t (p. 12). un(t) means |t| = ⊤.

The program uses no channel. It is a progress failure of the constant fix under
infinite types and says nothing about levels. No program that types and
deadlocks on channels has turned up (padovani-novara.md, section 4).


=====================================================================
1. fix applied to fix
=====================================================================

Program.

  ⟨(λ_.()) (fix fix)⟩

Why it types.

  Let s be the infinite tree with s = s → s, that is s = s →^{⊤,⊥} s. Every
  infinite branch of s passes through infinitely many arrows, so s meets the
  contractiveness condition (p. 12). |s| = ⊤, so un(s).
  fix has every type (t → t) → t (p. 7). At t = s the tree (s → s) → s equals
  s → s, because s → s = s.
    ∅ ⊢ fix : s → s & ⊥        T-Const at t = s, read as s → s
    ∅ ⊢ fix : s & ⊥            T-Const at t = s, read as s
  fix fix is T-App with τ₁ = τ₂ = ⊥. It asks ⊥ < |∅| = ⊤ and ⊥ < ⊤, the level
  of s → s. Its type is s and its effect ⊥.
  λ_.() : s → unit is T-Fun. The body () is T-Const in the environment _ : s,
  which needs un(_ : s), and |s| = ⊤. The closure is typed in ∅, so its level
  is ⊤, and the body has effect ⊥.
  (λ_.()) (fix fix) is T-App. It asks ⊥ < ⊤ and ⊥ < ⊤. Its type is unit and
  its effect ⊥.
  T-Thread gives ∅ ⊢ ⟨(λ_.()) (fix fix)⟩.

Why it deadlocks.

  Values are k, a, λx.e and send v (p. 5), and wrap v (p. 13). λ_.() is a
  value, so the reduction context v E puts the hole at fix fix. Its function
  part fix and its argument fix are both values. The only rule for fix is
  fix λx.e → e{fix λx.e/x} (p. 5), and the argument fix is no abstraction.
  β needs an abstraction in function position, and the rules for send, recv,
  fork and new do not match. So no rule applies. fix fix is no value either.
  The thread is irreducible and is not ⟨()⟩. By Definition 1 (p. 14) the
  process is not deadlock free, which contradicts Theorem 2 (p. 14).

  The program needs infinite types. With finite types fix fix needs
  t = t → t, which no finite type solves. No other constant has a type of the
  form u → u with latent effect ⊥, so fix fix is the only stuck application.
  The same holds for fix applied to any value of type s that is no
  abstraction.


=====================================================================
2. Repairs
=====================================================================

R1. Recursion as a binder, as in the technical report hal-00954364 (TR p. 6
    and p. 7). rec x e is typed by

      un(Γ)     Γ, x : t ⊢ e : t & ⊥
      ───────────────────────────────
      Γ ⊢ rec x e : t & ⊥

    and rec x e → e{rec x e/x} always applies.

R2. fix only in the form fix λx.e. The constant stays, and the grammar admits
    it only applied to an abstraction. Every use of fix in the chapter has this
    form (Example 1 on p. 5, Example 4 on p. 13). This is the repair the stage 2
    fragment v1 takes.

Neither repair changes a rule about levels. The progress argument of the
report (Lemma A.16, TR p. 16) then covers fix as it covers rec.
