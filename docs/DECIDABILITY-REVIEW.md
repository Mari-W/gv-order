## Lemma 1 and Theorem 1

**G1. The minimality step argues on the wrong carrier.** The proof shows that E
is closed under +1 and under slots that stay inside Sh(G), and concludes that E
contains ≡_{W_G} restricted to Sh(G). That inference needs a congruence on all
points, because ≡_{W_G} is the least relation closed under both laws on the whole
carrier. E is not one. If x E y with x ≠ y and x[i] lies outside Sh(G), slot
congruence forces x[i] ≡ y[i], and E does not contain that pair.

Fix. Let O be the equivalence on points outside Sh(G) generated by the pairs
u[w] + n ≡ v[w] + n with u E v and w nonempty. Sh(G) is prefix closed, so slots of
outside points stay outside, and +1 keeps the shape. E ∪ O is then a congruence
that contains the base aliases, and its restriction to Sh(G) is E. The same
observation is what Theorem 1 already uses for the outside part, so the fix costs
one paragraph.

The inclusion E ⊆ ≡_{W_G} is right. The slot-closure step is right as well,
because alias transfer gives shape(z_j).i ∈ Sh(G) for every z_j on the chain, and
the instance with word w.i and ν_{k+1} = 0 relates z_j[i] to z_{j+1}[i].

Theorem 1 is correct given Lemma 1. ORDERS-SPEC §5 adds no law for ≺ beyond
program order, so the order of W_G is (≡ ; (facts ∪ program order) ; ≡)⁺, and
strictness is irreflexivity on classes. The outside part is closed except for
program order, and its aliases equate offsets. The hypothesis (S) is not used.

## Theorem 3 and SFZ

**The algorithm.** I checked every step of the proof and found no error.

- Invariant. A valid walk W cuts only roles in S(W). If S(W) ⊆ S, line 3 keeps W,
  and the edge counts of W satisfy LP_S(H, e) for every e on W, so W ⊆ E′ and
  S(W) ⊆ cut(E′). Line 6 keeps S(W) ⊆ S. Each recursive call restarts with
  S = cut(H|Q) ⊇ S(W), so the invariant holds per call.
- Euler step. Every edge in the support of an integral solution x^e is itself
  feasible after scaling, so the support of Σ x^e is exactly E′. With k = 1 the
  balanced multigraph is connected, and one Euler circuit uses every edge of E′.
  It therefore contains the strict edge that line 5 found and cuts every role in S
  because line 6 passed. The strict-edge requirement survives because the circuit
  covers all of E′, and line 5 is checked on E′ itself.
- ℕ instead of ℤ. Lemma 2 shifts every uncut role up to N = C + nΔ + 1, where n is
  the length of the walk. The Euler circuit can be long, but N is chosen after the
  walk, so the bound is harmless. Free and cut roles restart at N on each segment.
- Termination. Line 6 strictly shrinks S. Line 9 recurses only when k ≥ 2, and
  each H|Q has fewer vertices. Components partition V(H), so the calls at one depth
  touch disjoint subgraphs. The bound of O(|V| · (|roles| + 1) · |E|) LP tests is
  right.

**G2. 𝒢 is not always a graph of unit schemas.** §3 says that the schemas of A(G)
"share the roles of s and s′ and the fresh roles ν_k". This fails when a shared
variable κ sits at the offset of s and at a non-offset coordinate of s′. Then s + ν₀
has the coordinate κ + c + ν₀, a sum of two variables, which §1.2 does not allow
and §3 assigns no role or shift. Take the delegation alias

```
(e, κ) ≡ (c[κ][1], 0)            e ≠ c,  (D), (R), (S) hold
A(G) ∋ (e, κ+ν₀) ≡ (c[κ][1], ν₀)
```

Its instances relate (e, m) to (c[k][1], m − k) for all k ≤ m. No finite set of
unit schemas has these instances. A unit schema fixes m − k, or fixes m, or fixes
k, so finitely many schemas cover only finitely many values of one of them. Lemma 2
and SFZ therefore have no input for this G. The same case appears for every k ≥ 1,
because the offset of s + ν₀ becomes the first index coordinate after [i₁].

Without constants the same shape occurs with a free target offset,
(e, κ) ≡ (c[κ][1], κ′). Theorem 3 is stated for constant-free G, so G2 hits it
directly.

Fix. Either add a side condition (offset alignment). It requires that a shared
variable at the offset of one side of an alias sits at the offset of the other
side. Under it, κ + ν₀ occurs on both sides and renames to one variable. Or extend
Lemma 2 to edges that relate x_offset on one side to x_index + x_offset on the
other, which is a different problem. The doc's own example (delegation under
recursion, §1.3) is of the bad form as soon as the payload alias carries κ, so the
side condition is not free.

**Scope of §0.** §0 says that the free-coordinate extension of ORDERS-SPEC §16 "is
Theorem 3". Theorem 3 needs constant-free G, and every slot point x[i] carries the
constant offset 0. The sender gate (c, κ) ≺ (c[κ][1], 0) of §1.3 is therefore
outside Theorem 3 and needs Theorem 4 with (M). Only the receiver schema of §16 on
its own is constant-free.

## Theorem 2

**G3. "S = ∅ throughout" depends on the reading of "cut".** §3 defines "e cuts r"
as "otherwise", so an edge whose two ends both lack r cuts r. If 𝒢 has weak
components with different role sets, cut(𝒢) ≠ ∅ although every edge shares every
role of its ends. The result is unaffected, because those roles have no defined
shift on those edges and dropping their LP constraint changes nothing. Fix. Let an
edge share r with shift 0 when r is absent at both ends.

With that reading S stays ∅, line 6 never fires, and SFZ is ZCYCLE with the
early No at line 5. The bound of O(|V| · |E|) LP tests matches Kosaraju–Sullivan's
Thm 3.3. The remark that weak edges alone give harmless zero cycles is right.

## Theorem 5

Correct. I checked each point the brief raised.

- Encoding. ⟨q; t, x, y⟩ = (a[t][q][x][1][y][1], 0) has shape a.q.1.1, depth 3,
  coordinates (t, x, y, 0). Each schema is unit and satisfies (D). Roles join only
  equal coordinate positions across the state shapes, so (R) holds. With no alias
  schemas Sh(G) is the prefix closure, which is finite, so (S) holds.
- World laws. There are no aliases, so ≡ is the identity and successor and slot
  congruence add nothing. ORDERS-SPEC §5 has no law x ≺ x[i], so prefix points
  connect to nothing but their own program order. Program order leaves offset 0,
  and every schema needs offset 0 at both ends, so program order lies on no cycle.
- Zero tests. The zero branch needs the constant 0 and the decrement branch needs
  κx + 1 ≥ 1, so exactly one transition applies to each configuration.
- M halts ⇒ not strict. The run from ⟨q₀; 0, 0, 0⟩ reaches ⟨h; T, x, y⟩, cleanup
  empties x, y and t, and the last edge closes the cycle.
- Not strict ⇒ M halts. Machine edges raise t. Cleanup edges either lower x + y + t
  or move from h_x to h_y to h_t. So every cycle uses the last edge, the only edge
  into ⟨q₀; 0, 0, 0⟩. From there the out-edges are deterministic, and the cycle
  returns only if the run reaches h.
- (M) fails. The self-loops of h_x and h_t have shift −1 on constant-carrying roles.
